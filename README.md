AstraCore — Python 3D Editor (Early Planning Stage)
AstraCore is a Python‑based 3D editor project built using PySide6, QOpenGLWidget, and Python 3.14.
The project is currently in the planning phase, and I am looking for a serious collaborator to help build the engine from scratch.

This repository intentionally contains only this README.md.
The full folder structure and codebase will be created together once a collaborator joins.

Project Vision
AstraCore aims to become a lightweight, modular 3D editor featuring:

Custom rendering pipeline

OpenGL viewport

OBJ/GLB import support

AI‑assisted workflow (Gemini + local LLMs)

Clean UI built with PySide6

This is a long‑term learning and development project.
